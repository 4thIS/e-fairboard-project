# 7.5" 800×480 웹 재설계 (흑백 1차) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 스펙 [docs/web/2026-07-15-800x480-web-redesign-design.md](../../web/2026-07-15-800x480-web-redesign-design.md) — 캔버스를 800×480(세로 480×800)으로 바꾸고 템플릿 5종을 비례 확대(제목 48/본문 32/부스 64px) 재배치하며, 미리보기를 컨테이너 박스 맞춤 축소로 전환한다.

**Architecture:** `TemplateDef`는 이미 캔버스를 속성으로 갖고 `field_avail_w`가 그 값을 쓴다(커밋 1b92c79). 그래서 백엔드는 **캔버스 기본값과 좌표만** 바꾸면 잘림 계산이 자동으로 맞는다. 생성기는 이미 캔버스를 내보내므로 `node/templates.h`는 재생성만 한다. 프론트 `EpaperPreview`는 정수 배율 캡을 **박스 맞춤 분수 축소**로 교체한다.

**Tech Stack:** Python 3.10 / FastAPI / pytest — Vue 3 + TS + vitest. 새 의존성 없음.

## Global Constraints

- 브랜치 `wj`. main 직접 push 금지 (CLAUDE.md).
- **흑백만.** 적색(3색)은 이번 범위 밖 (스펙 §1, v0.3).
- `node/lib/node_core/include/node/templates.h`는 `tools/gen_templates.py` **생성물** — 손으로 고치지 않고 재생성만. `layout.cpp`·`main.cpp`는 준표 영역, 건드리지 않는다.
- `app/protocol/`의 다른 파일·`app/simulator/`는 건드리지 않는다.
- 폰트 크기는 **16의 정수배만**(16/32/48/64px). `scale_for(font_px)=font_px//16`.
- 백엔드 테스트: `cd server/backend; .venv\Scripts\python.exe -m pytest -q` / 프론트: `cd server/frontend; npm test`
- 드리프트: `python tools/gen_templates.py --check` (표준 라이브러리만, venv 불필요)

- [ ] **Step 2: EpaperPreview — scale prop 을 박스 맞춤으로 교체**

`server/frontend/src/components/EpaperPreview.vue`의 `<script setup>` 상단 import·props·previewScale 교체:
```ts
import { DEFAULT_CANVAS, type TemplateDef } from '../epaper/types'
```
```ts
const props = withDefaults(defineProps<{
  template: TemplateDef | null
  fields: Record<string, string>
  qrUrl?: string
  boxW?: number
  boxH?: number
}>(), { qrUrl: '', boxW: 296, boxH: 128 })

/** 캔버스는 템플릿의 속성. 템플릿이 없으면 가로 빈 화면. */
const canvas = computed(() => props.template?.canvas ?? DEFAULT_CANVAS)

/** 박스(boxW×boxH) 안에 폭·높이 둘 다 넘지 않게 축소. 분수 배율 허용.
 *  가로(800×480)는 폭이, 세로(480×800)는 높이가 제약이 되어 한 공식으로 둘 다 처리(스펙 §6). */
const previewScale = computed(() =>
  Math.max(0.01, Math.min(props.boxW / canvas.value.w, props.boxH / canvas.value.h)))
```
`import { DEFAULT_CANVAS, MAX_PREVIEW_H, ... }`에서 `MAX_PREVIEW_H`가 사라졌는지 확인.
`<template>`의 `.epd`·`.inner` 스타일은 그대로(이미 `canvas.w * previewScale` 사용). QR·행 렌더도 변경 없음.

- [ ] **Step 3: NodeCard — 뷰포트 배율 대신 박스 전달**

`server/frontend/src/components/NodeCard.vue`의 `<script setup>`에서 winW·onResize·previewScale
블록(대략 아래 3줄 + resize 리스너)을 **삭제**한다:
```ts
// 삭제 대상:
const winW = ref(window.innerWidth)
const onResize = () => { winW.value = window.innerWidth }
onMounted(() => window.addEventListener('resize', onResize))
onUnmounted(() => window.removeEventListener('resize', onResize))
const previewScale = computed(() => (winW.value < 1280 ? 1 : 2))
```
이 컴포넌트에서 `onMounted`/`onUnmounted`는 resize 리스너 전용이었으므로, vue import를 정리한다:

import { computed, ref } from 'vue'

(`ref`는 `pinging`에서, `computed`는 여러 곳에서 계속 쓴다.)
