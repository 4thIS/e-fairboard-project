# 회로 설계 — 노드 배선 가이드

> 담당: 효민 · 작성 2026-07-22 · v0.3 개정 2026-07-28 · 기준: [HARDWARE.md](HARDWARE.md) §3·§6
>
> **SX1262+ESP32-S3 통합보드(예: T3S3/Heltec V3) + MCP23017 I2C 익스팬더 + Waveshare 12.48"
> e-Paper(1304×984, 흑백 듀얼패널)** 노드 1대분 배선. 실물 확인 결과 패널이 7.5" 3색에서
> 12.48" 흑백으로, LoRa가 별도 UART HAT에서 ESP32 통합보드로 바뀌었다(교수님 지시).
> `docs/HARDWARE.md`가 BOM·핀맵 원본이고, 이 문서는 실제 결선 순서를 눈으로 따라갈 수 있게
> 회로 단위로 풀어 쓴 것이다. **⚠️ 표시 항목은 통합보드 구매·실물 확인 전까지 가정.**

## 0. 확인 필요 (실물/구매 대조 전)

- [ ] 통합보드 최종 모델(T3S3 / Heltec WiFi LoRa32 V3 등) — 미확정
- [ ] 통합보드의 실제 SCK/MOSI/SDA/SCL, LoRa NSS/RST/BUSY/DIO1 GPIO 번호 — 구매 후 데이터시트로 확정
- [ ] 915M 밴드 여부(KR920 스트레치)·안테나 동봉 여부
- [ ] e-Paper 12.48"이 흑백(듀얼)인지 "(B)" 3색 모델인지 — 사진상 흑백으로 추정
- [ ] MCP23017 I2C 주소·풀업 저항값
- [ ] 서버측 HAT 연결 방식 — 이번 개정 범위 밖, 우진과 별도 확인

        │  (LoRa 920MHz, 안테나필수)     │                │ (우리가 못 바꿈)
        └───────────────┬───────────────┘                │

## 2. LoRa 회로 (통합보드 온보드 SX1262)

⚠️ 통합보드 내부에서 SX1262가 이미 SPI로 배선돼 있어 우리가 GPIO를 정할 수 없다. NSS/RST/BUSY/DIO1의
정확한 GPIO 번호는 구매한 보드(T3S3 / Heltec WiFi LoRa32 V3 등)의 공식 예제 코드·pinout 문서로
확정한다 — 효민, 보드 구매 후 갱신.

- 안테나는 보드에 동봉/온보드 여부 확인 필요(§0) — **안테나 미장착 상태로 송신 금지**는 동일하게 적용.
- 전원 라인(VCC-GND) 바로 옆에 **470µF + 0.1µF** 병렬 캐패시터 — LoRa 송신 순간 돌입전류(~120mA) 완충용.

## 3. e-Paper 12.48" 회로 (SPI + MCP23017)

| 신호 | 개수 | 연결 대상 | 비고 |
|------|:---:|:---:|------|
| CS_M1 / CS_S1 / CS_M2 / CS_S2 | 4 | MCP23017 GPB0~GPB3 | 마스터/슬레이브 2조 |
| DC (M1·S1 공유) / DC (M2·S2 공유) | 2 | MCP23017 GPB4, GPB5 | |
| RST (M1·S1 공유) / RST (M2·S2 공유) | 2 | MCP23017 GPB6, GPB7 | |
| BUSY_M1 / BUSY_S1 / BUSY_M2 / BUSY_S2(입력) | 4 | MCP23017 GPA0~GPA3 | GPA4~7 예비 |
| SCK / MOSI | 2 | 통합보드 네이티브 GPIO | ⚠️ 번호 미확정, e-Paper 전용(LoRa SPI는 내부 전용이라 공유 불가) |
| VCC/GND | — | 3V3 / GND | |

- MISO 미사용(쓰기 전용).
- CS/DC/RST는 SPI 트랜잭션 내내 유지되는 신호라 바이트 단위로 바뀌지 않음 — I2C 익스팬더로 충분.
  BUSY도 폴링이라 무방.
- 출처: Waveshare 12.48inch e-Paper Module 공식 데모(`esp32\wifi\DEV_Config.h`)의 핀 배정을
  MCP23017 채널로 재매핑한 것 — 원 핀 번호는 소프트웨어 정의라 그대로 안 써도 됨.

## 4. MCP23017 회로 (I2C)

```
통합보드 SDA/SCL ─► MCP23017 SDA/SCL   (⚠️ 통합보드 GPIO 번호 미확정)
통합보드 3V3/GND ─► MCP23017 VCC/GND
SDA/SCL 라인에 풀업저항(보통 4.7kΩ) — 통합보드에 이미 있으면 생략
```

- ⚠️ I2C 주소(A0~A2 핀으로 설정, 기본 0x20)와 풀업 저항값은 실물 확인 후 확정.

## 5. 전원 회로

```
18650(3.0~4.2V) ─► TP4056(USB-C 충전) ─► MT3608(부스트, 트림팟으로 5V 조정) ─► 통합보드 VIN
                                                                              └─ 470µF 벌크캡
통합보드 3V3 ─► MCP23017 VCC, e-Paper VCC   (공통 GND)

18650(+) ─►[100kΩ]─┬─► 통합보드 배터리 ADC 핀(⚠️ 번호 미확정)
                    └─►[100kΩ]─► GND
```

- **MT3608 출력 조정**: 통합보드에 물리기 전 트림팟으로 정확히 5V 맞추고 멀티미터로 확인(과전압 시 손상).
- **배터리 분압**: 100kΩ/100kΩ로 절반 분압 후 ADC 핀으로 읽음 → 실제 전압 = ADC값×2.
- ⚠️ 12.48" 흑백 패널은 전체 갱신에 ~8초 소요(Waveshare 위키 기준) — 배터리·부스트 용량 재검토는
  통합보드 확정 후 딥슬립 전류까지 포함해 재계산.

## 6. GPIO/채널 전체 참조표

| 배치 | 기능 | 연결 대상 |
|:---:|------|------|
| MCP23017 GPB0~GPB3 | e-Paper CS×4 | e-Paper CS_M1/S1/M2/S2 |
| MCP23017 GPB4~GPB5 | e-Paper DC×2 | e-Paper DC(공유×2) |
| MCP23017 GPB6~GPB7 | e-Paper RST×2 | e-Paper RST(공유×2) |
| MCP23017 GPA0~GPA3 | e-Paper BUSY×4(입력) | e-Paper BUSY_M1/S1/M2/S2 |
| MCP23017 GPA4~GPA7 | 예비 | — |
| 통합보드 네이티브(⚠️ 미확정) | SPI SCK/MOSI | e-Paper CLK/DIN 전용 (LoRa SPI 공유 불가) |
| 통합보드 네이티브(⚠️ 미확정) | I2C SDA/SCL | MCP23017 + (온보드 OLED) |
| 통합보드 네이티브(보드 고정) | LoRa NSS/RST/BUSY/DIO1 | 온보드 SX1262 |
| 통합보드 네이티브(⚠️ 미확정) | 배터리 전압(ADC) | 100k/100k 분압점 |

⚠️ 표시 항목은 통합보드(T3S3/Heltec V3 등) 최종 모델 구매 후 그 보드의 공식 pinout 문서로 확정 — 효민.
