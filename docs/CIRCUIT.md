# 회로 설계 — 노드 배선 가이드

> 담당: 효민 · 작성 2026-07-22 · 기준: [HARDWARE.md](HARDWARE.md) §3·§6 확정 핀맵
>
> ESP32 DevKitC + SX1262 LoRa HAT(UART) + e-Paper 7.5" 800×480 3색 노드 1대분 배선.
> `docs/HARDWARE.md`가 BOM·핀맵 원본이고, 이 문서는 실제 결선 순서를 눈으로 따라갈 수 있게
> 회로 단위로 풀어 쓴 것이다. **⚠️ 표시 항목은 실물 확인 전까지 가정.**

## 0. 확인 필요 (실물 대조 전)

- [ ] LoRa HAT VCC 전압 — 3V3인지 5V 요구인지
- [ ] M0/M1 모드 조합 의미 — Ebyte 계열(M0=0,M1=0 전송모드) 가정, 데이터시트로 재확인
- [ ] 915M 밴드 여부·안테나 동봉 여부
- [ ] e-Paper 7.5" 커넥터/구동전압이 2.9"용과 같은지
- [ ] 서버측 HAT USB 내장 여부(→ USB-TTL 어댑터 필요 여부)

## 2. LoRa HAT 회로 (UART)

| ESP32 GPIO | 신호 | HAT 핀 | 비고 |
|:---:|------|:---:|------|
| 3V3 | 전원 | VCC | ⚠️ 전압 확인 전 |
| GND | 접지 | GND | |
| 16 | UART2 RX | TXD | HAT → ESP32 |
| 4 | UART2 TX | RXD | ESP32 → HAT |
| 32 | 모드 선택0 | M0 | |
| 33 | 모드 선택1 | M1 | |
| 35 | 상태 읽기(입력전용) | AUX | |
| — | — | ANT | **안테나 미장착 상태로 송신 금지** |

- `Serial2.begin(9600, SERIAL_8N1, 16, 4)` — 기본 UART2 핀(16/17) 중 17은 e-Paper CS가 쓰고 있어 커스텀 매핑.
- 전원 라인(VCC-GND) 바로 옆에 **470µF + 0.1µF** 병렬 캐패시터 — LoRa 송신 순간 돌입전류(~120mA) 완충용.

## 3. e-Paper 7.5" 회로 (SPI)

| ESP32 GPIO | 신호 | 패널 핀 |
|:---:|------|:---:|
| 3V3 | 전원 | VCC |
| GND | 접지 | GND |
| 18 | SCK | CLK |
| 23 | MOSI | DIN |
| 17 | CS | CS |
| 25 | DC | DC |
| 26 | RST | RST |
| 27 | BUSY(입력) | BUSY |

- MISO 미사용(쓰기 전용). LoRa가 UART로 빠지면서 SPI는 e-Paper 단독 — 버스 공유 이슈 없음.

## 4. 전원 회로

```
18650(3.0~4.2V) ─► TP4056(USB-C 충전) ─► MT3608(부스트, 트림팟으로 5V 조정) ─► ESP32 VIN
                                                                              └─ 470µF 벌크캡
ESP32 3V3 ─► LoRa HAT VCC, e-Paper VCC   (공통 GND)

18650(+) ─►[100kΩ]─┬─► ESP32 GPIO34 (배터리 전압 ADC1)
                    └─►[100kΩ]─► GND
```

- **MT3608 출력 조정**: ESP32에 물리기 전 트림팟으로 정확히 5V 맞추고 멀티미터로 확인(과전압 시 ESP32 손상).
- **배터리 분압**: 100kΩ/100kΩ로 절반 분압 후 GPIO34(ADC1, Wi-Fi와 무충돌)로 읽음 → 실제 전압 = ADC값×2.
- ⚠️ 7.5" 3색 패널은 전체 갱신 시 소비전류가 크다(~15~20초 지속) — 배터리·부스트 용량 재검토는 패널 데이터시트 확보 후 별도 계산.

## 5. GPIO 전체 참조표

| GPIO | 기능 | 연결 대상 |
|:---:|------|------|
| 3V3 | 전원 출력 | LoRa VCC, e-Paper VCC |
| GND | 공통 접지 | LoRa GND, e-Paper GND |
| 4 | UART2 TX | LoRa RXD |
| 16 | UART2 RX | LoRa TXD |
| 17 | SPI CS | e-Paper CS |
| 18 | SPI CLK | e-Paper CLK |
| 23 | SPI MOSI | e-Paper DIN |
| 25 | SPI DC | e-Paper DC |
| 26 | SPI RST | e-Paper RST |
| 27 | SPI BUSY(입력) | e-Paper BUSY |
| 32 | 모드 선택0 | LoRa M0 |
| 33 | 모드 선택1 | LoRa M1 |
| 35 | 상태 읽기(입력전용) | LoRa AUX |
| 34 | 배터리 전압(ADC1, 입력전용) | 100k/100k 분압점 |
| 2 | 상태 LED(온보드) | — |

회피 확인: GPIO0/2/5/12/15(스트래핑) 출력 미사용, 6~11(내장 Flash) 미사용 — 위 배정에 해당 없음.
