# 하드웨어 — BOM · 핀맵 · 전원

대상: 2노드 MVP (노드 2 + 예비 1). ESP32 통일, **SX1262 LoRa HAT(UART)** + e-Paper **7.5" 800×480 3색**.

> **v0.2 개정 (2026-07-15)** — 하드웨어 확정에 맞춘 개정. 팀장(우진) 주도로 결정 사실을 반영하고,
> **핀맵·전원의 구체 재설계는 효민**이 진행한다(⚠️ 표시 항목). 두 가지가 근본적으로 바뀌었다:
> ① **게이트웨이 ESP32 제거** — 서버 PC에 SX1262 HAT 직결([PROTOCOL.md](PROTOCOL.md) v0.2).
> ② **LoRa가 SPI → UART** — HAT의 온보드 MCU가 UART/AT로 노출한다. "LoRa·e-Paper 공유 SPI 버스"
> 전제가 사라진다(§2). 라디오 칩은 여전히 SX1262지만 인터페이스가 다르다.

## 2. 인터페이스 버스  〔개정 — LoRa가 SPI에서 빠짐〕
- **LoRa(SX1262 HAT) = UART.** SPI 아님. TX/RX + M0/M1(모드) + AUX(상태) 신호. GPIO 배정은 효민(§3).
- **e-Paper 7.5" = SPI** (쓰기 전용, MISO 미사용). LoRa가 빠져 **SPI는 e-Paper 단독**이 된다
  (버스 공유·CS 분리 이슈 소멸 → 배선 단순화).

| 신호 | ESP32 GPIO | 연결 |
|------|:---:|------|
| SCK  | 18 | e-Paper CLK |
| MOSI | 23 | e-Paper DIN |
| (MISO) | — | e-Paper 미사용 |

## 3. 노드 핀맵 (ESP32 + SX1262 HAT + 7.5" e-Paper)

### LoRa SX1262 HAT (UART)  ⚠️ 효민 재설계
SPI 시절 핀맵(NSS/DIO1/RST/BUSY)은 **폐기**. HAT은 UART로 붙는다. 필요한 신호:

| HAT 신호 | 역할 | ESP32 |
|------|------|:---:|
| TXD/RXD | UART 데이터(9600) | ⚠️ UART2 등 배정 — 효민 |
| M0, M1 | 모드(전송/설정) — 설정모드로 AT 레지스터 기록 | ⚠️ GPIO 2개 — 효민 |
| AUX | 송수신 상태(busy) | ⚠️ GPIO 1개 — 효민 |
| VCC/GND | 전원 | 3V3 또는 5V(HAT 사양 확인) / GND |
| ANT | 안테나 (**무안테나 송신 금지**) | — |

### e-Paper 7.5" (Waveshare SPI)  — SPI 신호는 유지, 패널만 교체
| 모듈 핀 | ESP32 GPIO |
|------|:---:|
| CS | 17 |
| DC | 25 |
| RST | 26 |
| BUSY | 27 |
| CLK/DIN | 18/23 |
| VCC/GND | 3V3/GND (⚠️ 7.5" 소비전류 — §5) |

- ⚠️ 7.5" 패널 커넥터/구동전압이 2.9"와 다를 수 있다(다수 패널은 별도 HAT/어댑터 보드 사용).
  실제 결선·구동 전압은 효민이 패널 데이터시트로 확인.

### 보조
| 기능 | ESP32 GPIO | 비고 |
|------|:---:|------|
| 배터리 ADC | 34 | ADC1, 입력전용, 100k/100k 분압 |
| 상태 LED | 2 | 온보드 |

### 펌웨어 핀 선언
- e-Paper: `GxEPD2_3C<GxEPD2_750c_Z08, ...>` (CS=17, DC=25, RST=26, BUSY=27).
- LoRa: RadioLib(SPI) 아님 — **HAT UART + AT 명령**. `Serial2` 등으로 제어(준표, PROTOCOL.md §1).

## 4. 서버측 HAT 연결  〔신규 — 게이트웨이 핀맵 대체〕
- **게이트웨이 ESP32가 없다.** 서버 PC에 SX1262 HAT을 직접 연결한다.
- ⚠️ 연결 방식 확인(효민): HAT이 USB를 내장하지 않으면 **USB-TTL 어댑터**로 UART를 PC COM 포트에
  노출한다(레퍼런스는 COM 포트로 접속). M0/M1은 설정 시 점퍼/스위치로 제어.
- 라디오 파라미터는 `server/tools/config_hat` 형식 도구로 AT 레지스터 1회 기록(멱등).

## 5. 전원 결선 (노드)  〔개정 — 7.5" 3색 소비전류 재검토〕
```
18650(3.0~4.2V) ─ TP4056 ─ MT3608(부스트 5V) ─ ESP32 VIN(5V)
                                              └ 470µF 벌크캡(LoRa TX 돌입전류)
ESP32 3V3 ─ SX1262 HAT VCC, e-Paper VCC ;  공통 GND
```
- ⚠️ **7.5" 3색 갱신 전류가 크다**(2.9" 대비). 부스트·배터리·캡 용량이 충분한지 재검토 — 효민.
  3색 전체 갱신은 ~15~20초로 길어 순간·누적 소비가 늘어난다.
- ⚠️ **DevKitC 딥슬립 수 mA**(AMS1117+CP2102) → "2주 동작"엔 베어 WROOM 권장. 데모/MVP는 DevKitC OK.
- ⚠️ **LoRa TX 돌입전류(~120mA)** → HAT VCC 근처 470µF+0.1µF 디커플링.
- 저전력 대안: 부스트 대신 저드롭 LDO(AP2112-3.3) 직접 3V3 급전(HAT·패널 전압 요구 확인 후).

## 6. 핀 충돌 점검  ⚠️ UART LoRa 배정 후 재확인 (효민)
- e-Paper SPI: 17,25,26,27(+18,23). LoRa UART/모드/AUX GPIO는 효민 배정 후 이 표에 합류.
- 회피: GPIO0/2(부팅·LED)/12/15(스트래핑) 출력 미사용, 6~11(내장 Flash) 미사용.
- 배터리 ADC는 Wi-Fi와 충돌 없는 **ADC1(GPIO34)** 사용. UART2 기본핀(16/17)과 e-Paper CS(17)가
  겹치지 않게 배정 주의.

## 7. 조립 순서  〔개정〕
1. ESP32 단독 부팅 → 2. **SX1262 HAT + UART/AT 송수신(안테나)** → 3. e-Paper 7.5" + GxEPD2 출력
→ 4. 동시 동작 → 5. 배터리/부스트(7.5" 소비전류 확인) → 6. 딥슬립 전류 측정 → 7. 케이스.
