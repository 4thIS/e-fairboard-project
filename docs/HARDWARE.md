# 하드웨어 — BOM · 핀맵 · 전원

대상: 2노드 MVP (노드 2 + 예비 1). ESP32 통일, **SX1262 LoRa HAT(UART)** + e-Paper **7.5" 800×480 3색**.

> **v0.2 개정 (2026-07-15)** — 하드웨어 확정에 맞춘 개정. 팀장(우진) 주도로 결정 사실을 반영하고,
> **핀맵·전원의 구체 재설계는 효민**이 진행한다(⚠️ 표시 항목). 두 가지가 근본적으로 바뀌었다:
> ① **게이트웨이 ESP32 제거** — 서버 PC에 SX1262 HAT 직결([PROTOCOL.md](PROTOCOL.md) v0.2).
> ② **LoRa가 SPI → UART** — HAT의 온보드 MCU가 UART/AT로 노출한다. "LoRa·e-Paper 공유 SPI 버스"
> 전제가 사라진다(§2). 라디오 칩은 여전히 SX1262지만 인터페이스가 다르다.
>
> **v0.3 개정 (2026-07-28)** — 실물 확인 결과 e-Paper 패널이 **7.5" 3색 → 12.48" 1304×984 흑백
> 듀얼패널**(Waveshare 12.48inch e-Paper Module)로 최종 변경됐다. 또한 교수님 지시로 노드 LoRa는
> **ESP32와 통합된 보드**를 구매하기로 해 기존 "ESP32 DevKitC + 별도 SX1262 UART HAT" 조합을
> 폐기하고 **SX1262+ESP32-S3 통합보드**(예: LILYGO T3S3, Heltec WiFi LoRa32 V3 — 정확한 모델은
> 구매 후 확정)로 전환한다. 12.48" 패널은 마스터/슬레이브 2조 컨트롤러로 **14개 GPIO**가 필요한데
> ESP32-S3 통합보드는 온보드 LoRa·(있다면)OLED가 이미 여러 핀을 점유해 여유 GPIO가 ~10개뿐이라
> **I2C GPIO 익스팬더(MCP23017)**를 추가해 e-Paper 제어선을 나눠 받는다(§3). 서버측 HAT 연결(§4)은
> 이번 개정 범위 밖 — 우진과 별도 확인 필요.

## 2. 인터페이스 버스  〔v0.3 개정 — LoRa 통합·e-Paper 듀얼패널·I2C 익스팬더 추가〕
- **LoRa = SX1262 통합보드 온보드 SPI.** 더 이상 UART/HAT 아님 — 통합보드 내부에서 이미 배선되어 있어
  우리가 GPIO를 정할 수 없다(§3, 보드 데이터시트로 확정).
- **e-Paper 12.48" = SPI, 4개 슬레이브(CS×4) 공유 버스**(쓰기 전용, MISO 미사용). **전용
  SCK/MOSI 핀 필요** — 통합보드의 LoRa SPI는 내부 배선 전용이라 외부 헤더에 노출되지 않아
  공유 불가(Heltec V3 공식 핀맵으로 확인, 예: 온보드 SX1262가 GPIO8~14 점유·미노출).
- **I2C 버스 신규 추가** — MCP23017(e-Paper 제어선용, §3) + 통합보드 온보드 OLED(있는 경우) 공유.

| 신호 | 연결 | 비고 |
|------|------|------|
| SCK/MOSI | e-Paper CLK/DIN 전용 | 여유 GPIO에서 배정(구매 후 확정, LoRa SPI와 공유 불가) |
| SDA/SCL | MCP23017 + (온보드 OLED) | 통합보드 고정 핀(구매 후 확정) |

## 3. 노드 핀맵 (SX1262+ESP32-S3 통합보드 + MCP23017 + 12.48" e-Paper)

### LoRa (통합보드 온보드 SX1262)  〔v0.3 — 보드 고정, 미확정〕
통합보드 안에서 SX1262가 이미 SPI로 배선돼 있어 **우리가 GPIO를 고를 수 없다**. NSS/RST/BUSY/DIO1의
정확한 GPIO 번호는 구매한 보드(T3S3 / Heltec WiFi LoRa32 V3 등)의 공식 pinout 문서로 확정한다 — 효민.
(참고: Heltec WiFi LoRa32 V3 조사 결과 온보드 OLED RST=GPIO21, 외부 여유 GPIO는 약 10개
(GPIO1,2,4,5,6,7,19,20,47,48)뿐으로 확인 — 아래 12.48" 12개 제어선을 이 여유 핀만으로 못 받아서
MCP23017을 둔다.)

### e-Paper 12.48" (Waveshare, 듀얼패널)  〔확정 2026-07-28 — Waveshare 공식 데모 펌웨어 기준〕
출처: Waveshare 12.48inch e-Paper Module 위키 첨부 `esp32\wifi\DEV_Config.h`(공식 ESP32 데모 코드).
거기 핀 배정은 `#define`이라 하드웨어로 고정된 게 아니고, 아래처럼 우리 보드에 맞게 재배선하면 된다.

| 신호 | 개수 | 배치 | 비고 |
|------|:---:|:---:|------|
| CS_M1 / CS_S1 / CS_M2 / CS_S2 | 4 | MCP23017 GPB0~GPB3 | 마스터/슬레이브 2조 |
| DC (M1·S1 공유) / DC (M2·S2 공유) | 2 | MCP23017 GPB4, GPB5 | 2조가 각각 DC 공유 |
| RST (M1·S1 공유) / RST (M2·S2 공유) | 2 | MCP23017 GPB6, GPB7 | 2조가 각각 RST 공유 |
| BUSY_M1 / BUSY_S1 / BUSY_M2 / BUSY_S2 (입력) | 4 | MCP23017 GPA0~GPA3 | GPA4~7 예비 |
| SCK / MOSI | 2 | ESP32-S3 네이티브(§2) | e-Paper 전용 핀(LoRa SPI는 내부 전용, 공유 불가) |
| VCC/GND | — | 3V3 / GND | |

- CS/DC/RST는 SPI 트랜잭션 내내 유지되는 신호라 바이트 단위로 안 바뀜 — I2C 익스팬더(MCP23017)로
  충분. BUSY도 폴링이라 무방.
- MCP23017 ↔ ESP32-S3는 I2C(SDA/SCL, §2)로 연결.
- ⚠️ MCP23017 I2C 주소·풀업 저항값, 통합보드의 실제 SCK/MOSI/SDA/SCL GPIO 번호는 보드 구매 후 확정 — 효민.

### 보조
| 기능 | 배치 | 비고 |
|------|:---:|------|
| 배터리 ADC | 통합보드 여유 GPIO 중 1개 | 보드 구매 후 확정 |
| 상태 LED | MCP23017 GPA4~7 중 1개 또는 온보드 LED | 통합보드에 내장 LED 있으면 그걸 사용 |

### 펌웨어 핀 선언
- e-Paper: DEV_Config.h 스타일 매핑을 MCP23017 채널로 재작성 필요(위 표 기준) — 준표와 협의.
- LoRa: RadioLib(SPI, SX1262) — 통합보드 예제 코드의 NSS/RST/BUSY/DIO1 핀 정의를 그대로 사용
  (준표, PROTOCOL.md는 기존 UART/AT 전제에서 **네이티브 SPI 전제로 갱신 필요** — hm 범위 밖이라 준표에게 전달만).

## 4. 서버측 HAT 연결  〔신규 — 게이트웨이 핀맵 대체〕
- **게이트웨이 ESP32가 없다.** 서버 PC에 SX1262 HAT을 직접 연결한다.
- ⚠️ 연결 방식 확인(효민): HAT이 USB를 내장하지 않으면 **USB-TTL 어댑터**로 UART를 PC COM 포트에
  노출한다(레퍼런스는 COM 포트로 접속). M0/M1은 설정 시 점퍼/스위치로 제어.
- 라디오 파라미터는 `server/tools/config_hat` 형식 도구로 AT 레지스터 1회 기록(멱등).

## 5. 전원 결선 (노드)  〔v0.3 개정 — 12.48" 소비전류·MCP23017 반영〕
```
18650(3.0~4.2V) ─ TP4056 ─ MT3608(부스트 5V) ─ 통합보드 VIN/5V
                                              └ 470µF 벌크캡(LoRa TX 돌입전류)
통합보드 3V3 ─ MCP23017 VCC, e-Paper VCC ;  공통 GND
```
- ⚠️ **12.48" 패널 갱신 전류·시간이 7.5"보다 크다**(흑백 전체 갱신 ~8초, Waveshare 위키 기준). 부스트·
  배터리·캡 용량이 충분한지 재검토 — 효민. 패널이 4개 서브패널(마스터/슬레이브 2조)이라 순간 전류가
  분산될 수도 있음 — 실측 필요.
- ⚠️ **통합보드(ESP32-S3) 딥슬립 전류**는 보드 구매 후 데이터시트로 확인 — 효민.
- ⚠️ **LoRa TX 돌입전류(~120mA)** → 통합보드 전원 근처 470µF+0.1µF 디커플링.
- MCP23017 자체 소비전류는 무시 가능한 수준(수백 µA)이라 전원 설계에 별도 반영 불필요.

## 6. 핀 충돌 점검  〔v0.3 개정 2026-07-28 — 효민, 통합보드 미확정으로 일부 ⚠️〕
| 기능 | 배치 | 비고 |
|------|:---:|------|
| e-Paper CS ×4 | MCP23017 GPB0~GPB3 | 확정(§3) — 익스팬더 채널이라 보드 종류 무관 |
| e-Paper DC ×2 | MCP23017 GPB4~GPB5 | 확정 |
| e-Paper RST ×2 | MCP23017 GPB6~GPB7 | 확정 |
| e-Paper BUSY ×4 | MCP23017 GPA0~GPA3 | 확정, GPA4~7 예비 |
| e-Paper SCK/MOSI | ESP32-S3 네이티브 | ⚠️ 보드 구매 후 GPIO 번호 확정, e-Paper 전용 |
| MCP23017 SDA/SCL | ESP32-S3 네이티브 | ⚠️ 보드 구매 후 GPIO 번호 확정 |
| LoRa NSS/RST/BUSY/DIO1 | ESP32-S3 네이티브(보드 고정) | ⚠️ 보드 데이터시트로 확정, 우리가 재배선 불가 |
| 배터리 ADC | ESP32-S3 여유 GPIO 1개 | ⚠️ 보드 구매 후 확정 |

- Heltec WiFi LoRa32 V3 기준 확인된 외부 여유 GPIO: 1,2,4,5,6,7,19,20,47,48 (약 10개) — 위 네이티브
  핀(SCK/MOSI/SDA/SCL + LoRa 고정 4핀 = 8개) 배정에 빠듯하게 맞는 수준. **다른 모델(T3S3 등) 선택 시
  이 표를 그 보드 기준으로 다시 확인해야 함** — 효민.
- e-Paper 12개 제어선은 MCP23017로 옮겨서 보드 종류와 무관하게 확정해뒀다(위 4행).

## 7. 조립 순서  〔v0.3 개정〕
1. 통합보드 단독 부팅 → 2. **온보드 SX1262 LoRa 송수신(안테나)** → 3. MCP23017 I2C 통신 확인
→ 4. e-Paper 12.48" 출력 → 5. 동시 동작 → 6. 배터리/부스트(12.48" 소비전류 확인) → 7. 딥슬립 전류 측정 → 8. 케이스.
